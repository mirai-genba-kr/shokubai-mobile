# shokubai-mobile

日本触媒グループ 吸水性樹脂製造部向け「シリカチャージ記録」モバイル入力アプリの入口ページ。

## これは何か

中身は GAS（Google Apps Script）で動いているアプリを、iframe で表示しているだけの1枚。
GAS の `/exec` を直接開くと Google の警告バナーが出るため、それを避けるために置いている。

- **このリポジトリにお客様のデータ・認証情報は一切含まれない**
- アプリ本体（画面・API連携）は GAS 側にある

## 構成

```
index.html   GASアプリを iframe で表示するだけのページ
```

## 差し替え方

GAS の本番デプロイURLが変わったら `index.html` の `src` を書き換える。
